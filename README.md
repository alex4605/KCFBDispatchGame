# 高雄市消防局勤務指揮中心

Claude powered web game。

扮演高雄市消防局勤務指揮中心的指揮官：

- 受理報案電話，依案件派出車輛。
- 在全市地圖上看著車隊趕赴現場。
- 遇到重大火警時，親自進入現場指揮各小組救人滅火。

## 快速開始

- 下載後直接用瀏覽器開啟 `index.html`，不需要安裝或建置。
- 進線案件出現在右上列表，點選後在右下的案件詳情派遣車輛，車輛到場作業完成即結案。
- 空白鍵暫停；滑鼠滾輪縮放地圖、拖曳平移。

## 遊戲的三個層次

| 層次 | 做什麼 | 什麼時候 |
|---|---|---|
| 指揮中心（戰略層） | 受理、派遣、調度全市車輛、回覆現場請求、外部支援 | 一直都在 |
| 地圖現場模式 | 在全市地圖上放大，直接看見各現場的車輛、水線與人員 | 隨時放大地圖，或選取案件 |
| 戰術指揮 | 親自指揮建物火災現場的每一個小組 | 建物火災類案件首車到場後 |

山林火警另有「山火作戰圖」，在戰略層以分區派遣處置。

## 一、指揮中心

### 畫面

- **左欄：車輛動態。** 各分隊的車輛與狀態；跨縣市支援的車隊另外分組。
- **中央：全市地圖。** 分隊、醫院、案件、行進中的車輛與水線。
- **右欄：** 進線案件列表與案件詳情（通聯紀錄、ARR 派遣、水情、外部支援）。
- 進線列表按下即選取；滑鼠停在列表上時排序凍結，平常每 2 秒依剩餘時間重排。↑／↓ 在案件間切換。

### AI 通話（選用）

按右上角「AI 通話」：

1. 選擇供應商（Anthropic Claude 或 Google Gemini）。
2. 輸入自己的 API 金鑰並啟用。

之後新進線的報案人改由 AI 扮演，在通聯紀錄下方打字詢問，報案人會依案件實際狀況回答。

- **備援：** 沒啟用、連不上、金鑰無效或模型拒答時，自動改回腳本對話。
- **進線間隔：** AI 模式下拉長為 2.5 倍，讓受理員有時間問話。
- **金鑰：** 只存在瀏覽器的 localStorage，只送往所選供應商的 API 主機；費用依該帳號用量計算。
- **Gemini：** 請先按「測試連線」，會列出金鑰可用的模型；填的模型不存在時自動改用最接近的。

### 評鑑

- 評鑑從 100 起算、沒有上限，歸零即失去指揮權。
- **加分：**
  - 每件結案都會加分，案件等級越高加越多。
  - 親自指揮的戰術案件依結案報告等級另加：S +6、A +4、B +2、C +1。
  - 建物防護每保住一棟承受過山火的民宅也另加。
- **邊際效應：** 實際加分 = 基礎分 × 150 ÷（150 + 目前評鑑），評鑑越高加得越少。扣分不打折。

### 分隊與特搜

- **開局分隊（12 個）：** 特一、特二、苓雅、前鎮、鼓山、左營、楠梓、小港、旗津、鳳山，以及鄉間的旗山、林園。
- **可開設分隊：** 大寮、仁武、岡山、燕巢、美濃、大樹、六龜，從「採購」開設。
- **均勻分布：** 分隊位置依人口權重（市區建物＞郊區＞鄉鎮＞港區＞農地）分配責任區，每個分隊移到責任區重心附近的臨路空地，讓各區到場距離接近；特搜、旗津（離島）與鄉鎮分隊位置固定。
- **USAR：** 高雄的 USAR 只由第一、第二特搜分隊（特一、特二）執行。
  - 特搜的車同樣分 11、16、71……，另有 99（特搜醫療組：現場醫療支援，不後送）。
  - 特搜沒有 91、92 救護車。
  - 一般分隊的救助車不能擔任 USAR。

### 跨縣市支援

三級火警（有火警分級的看分級，其他火警看案類等級）才能請求，花費評鑑。請求位置在案件詳情的「外部支援」，或戰術畫面右側。

署特搜與輪值 Strike Force 也可支援重大救助案件：建物倒塌、大型工安、氣爆、邊坡崩塌、山區搜救、航空器、鐵路、捷運、遊覽車、侷限空間。

| 單位 | 花費 | 車隊（呼號） | 到場 |
|---|---|---|---|
| 臺南市消防局 | 評鑑 15 | 歸仁11、關廟11、仁德11、龍崎61、歸仁41 | 集結 4～5 分鐘，從北邊國道進入 |
| 屏東縣消防局 | 評鑑 10 | 新園11、萬丹11、里港71、屏東特搜 | 集結 4～5 分鐘，從東邊高屏溪橋進入 |
| 內政部消防署特種搜救隊 | 評鑑 12 | 署搜1、署搜2、署搜救助、署搜履 | 集結 6～7 分鐘，從北邊國道進入 |
| 輪值 USAR Strike Force | 評鑑 12 | 本週輪值縣市的特搜單位（取 3 個；單一分隊時另加救助車） | 依距離 4～17 分鐘 |

- **輪值：** 每週（7 個遊戲日）在各縣市特搜單位間輪替，呼號如「民權搜」「南雅搜」「一搜」「苗栗特搜」「臺中搜救犬隊」。
- **作業：** 支援車隊到場後與本局車輛一樣編組作業，也會出現在戰術畫面；任務結束直接返回原單位。
- **限制：** 請求後評鑑須保留 5 以上；每個案件每個單位只能請求一次。

**外縣市請求我方支援**

偶爾會有其他縣市來請求，以紫色「跨縣市支援請求」出現在進線列表。

- 點開可看需要的車種、支援時間與報酬，按「派遣支援」或「婉拒」。
- 2 分鐘內要回覆，逾時不扣分。
- 派出的車在支援期間（6～10 分鐘）不在轄區，返隊後依請求給評鑑與補助。

### 環保署化災應變隊

化災相關案件（化工廠、資源回收場、加油站、油罐車、化學物質洩漏等）可以請求。

- 隊員集結 5～8 分鐘後從林園出發；地圖上看得到集結倒數、行進路線與車隊。
- 到場後在戰術畫面加入「化災應變隊」一組：
  - 自備 A／B／C 級防護裝備，不受套數限制。
  - 化物辨識與止漏最快，也可開設除污站。
- 未進入戰術指揮的化災案件，應變隊到場後處置速度提升 25%。

## 二、全市地圖

地圖為 150×150 格：

- **左上：** 市區棋盤。
- **市區外圍：** 郊區過渡帶。
- **東側與南側：** 鄉間。

「全圖」可縮到看見整張地圖。

### 市區、郊區與鄉間

- **市區：** 棋盤街廓、密集建物；高雄港、愛河型運河、西側海岸、東北山林。
- **郊區（過渡帶）：** 市區東側與南側外圍（含小港機場一帶）。
  - 街廓較大、巷弄少，混有農地與鐵皮工廠，建物多為低矮透天。
  - 鄉間緊鄰市區的一圈，省道縣道兩旁蓋滿透天與工廠，再往外才是農田。
- **機場：** 場內不鋪路，外圍一圈環場道路，西側航廈有連外道路。場內畫有兩條跑道（跑道頭標線、邊燈）、滑行道、航廈、停機坪與飛機。
- **鄉間：**
  - 東緣是高屏溪，東北是山區，南側是海岸與成片魚塭，其餘為農田。
  - 旗山、美濃、大樹、林園、六龜為鄉鎮，農田間有散村。
- **放大後的細節：**
  - 旗山周邊香蕉園、山腳檳榔園、美濃一帶溫室、近海旱作，其餘以稻田為主。
  - 灌溉水圳、鄰溪堤防、魚塭打氣水車與漁電共生光電板。
  - 三合院、廟宇、學校操場、高壓電塔線。
  - 中低倍率顯示地名（各區、高屏溪、台灣海峽）。
- **鄉間案件：**
  - 人口少、案件少；沒有高樓、百貨、捷運等都會型案件，多了雜草火與鐵皮屋。
  - 地址如「旗山區中山路…」「美濃區農路旁…鄰」。
  - 距離遠，案件時限放寬約 45%。
  - 消防栓只在鄉鎮街道，偏遠處要靠水庫車。

### 道路生成

鄉間省道、縣道、鄉道先規劃大方向：起訖點之間放 1～2 個略為偏移的控制點。再以成本路徑搜尋鋪設：

- **沿用既有道路：** 成本很低，減少重疊與平行路。
- **緊鄰既有道路卻不在路上：** 成本較高，避免兩條路並排。
- **過河：** 成本很高，只在必要處架橋。
- **偏離規劃線：** 有小額成本，鋪出均勻的斜線；畫面上再以斜切轉角平滑。

鄉鎮是筆直的十字主街加上幾條小巷，小巷不會貼著既有道路平行走。

### 道路分級

道路依真實道路邏輯分成 11 級。地圖依等級畫出路寬、顏色與標線；中低倍率顯示路線標誌：國道綠底、省道與快速道路白底、縣道黃底、鄉道灰底。

| 等級 | 說明 |
|---|---|
| 高速公路（高架） | 國道一號、國道十號市區段；地面道路從橋下通過 |
| 高速公路（平面） | 國道十號郊區與鄉間段，兩側有護欄 |
| 高速公路匝道 | 交流道；只有這裡能上下國道 |
| 快速道路 | 台 88（高架），從國道一號往東到高屏溪 |
| 地下道 | 地面道路從平面國道下方穿過 |
| 省道 | 市區台 1；鄉間台 3、台 17、台 21、台 27（美濃—六龜，可通大型車）、台 29 |
| 縣道 | 縣 184（旗美）、縣 186（沿高屏溪）、縣 188（大寮—林園） |
| 市道 | 市區道路（幹道較寬，有白色虛線中線） |
| 鄉道 | 鄉鎮街道與鄉間支線（高 30、高 37 等） |
| 產業道路 | 農路與山區道路（大型車禁入） |
| 小徑 | 市區巷弄與鄉鎮小巷（大型車禁入） |

- **立體交叉：** 高架與地下道交會處分成「國道層」與「地面層」，兩層互不相通，車輛只能從匝道上下國道，路徑搜尋也遵守這個規則。
- **畫法：** 鄉間的斜向路段畫成連續的斜路；斑馬線只出現在市區與鄉鎮真正的路口（三向以上）。

### 地圖現場模式

大地圖放大到每格約 56 像素以上時，畫面內的案件直接在地圖上顯示現場：車輛、水線、射水、火煙、人員、指揮站、救護待命區、警戒帶、化災區劃。

案件標記改成災點上方的標籤，寫著案類、報數、受困人數與作業進度。

地圖右上的現場顯示按鈕可在三種方式間切換，瀏覽器會記住選擇：

| 按鈕 | 方式 |
|---|---|
| ◎ 大地圖放大（預設） | 選取案件時鏡頭飛到現場並放大；右欄全部留給案件詳情；雙擊案件進入戰術指揮 |
| ⇄ 現場面板放大 | 現場畫面放大到中央，大地圖縮到右欄 |
| ▭ 右欄小窗 | 大地圖在中央，現場畫面在右欄小窗 |

放大到現場模式時：

- **淡入：** 現場圖層在門檻前逐漸淡入。
- **全市縮圖：** 右下角出現全市縮圖，點按可移動視野。
- **邊緣指標：** 畫面外的案件以邊緣指標標示方向，點按就飛過去。
- **點選車輛：** 點現場車輛可選取該車。
- **晝夜變化：** 夜間整體壓暗，住家亮窗、路燈亮起，車輛警示燈更明顯。

## 三、山火作戰圖（山林火警）

山林火警不進入戰術指揮。首車到場後，選取案件時現場畫面會換成作戰圖，詳情面板出現分區派遣。

- **火場擴展：**
  - 火在大地圖格子上擴展，每格約 1 公頃。
  - 燃料：林地最多，草地、農地次之。
  - 阻隔：產業道路擋不太住火，其他道路與水域是阻隔。
  - 延燒受風向（火頭順風）、坡度（往上坡燒得快）與晝夜（夜間趨緩）影響。
- **分區：** 依風向把火線分成火頭、左翼、右翼、火尾。
- **派遣：** 在詳情面板把到場車輛派到分區，並指定任務：
  - **地面水線：** 壓制道路 2 格內最猛的火線，優先保護逼近民宅的火線。
  - **防火線：** 在火線外側隔一格清除植被，火燒不過去。
  - **自動分派：** 開啟時，新到車輛與火線消失的分區會自動改派；手動指定過的車輛不會被改。
- **外部支援：**
  - 空勤總隊直升機：5～7 分鐘抵達，吊桶灑水；夜間停飛。
  - 林務署與國軍地面班：集結 6～9 分鐘，開設防火線。
- **民宅：** 火線燒進民宅工寮，每處評鑑 -1。
- **建物防護戰術場景：** 火線逼近民宅時，可以「⚔ 建物防護戰術」就地指揮該聚落的防護。
  - **場景：** 由林地邊緣、防禦空間、3～4 棟民宅與工寮、聚落前的道路組成；林地那側對應作戰圖上火的來向。
  - **民宅受熱：** 外牆要累積受熱才會起燃；「周界防護」射水可讓外牆降溫。民宅燒毀每棟評鑑 -2。
  - **多處受威脅時：** 依急迫程度依序處理，完成一處自動轉往下一處。
- **結案：** 火場全滅後殘火監控 15 秒結案。

## 四、戰術指揮（建物火災）

### 適用案類與進入方式

- **適用案類：**
  - 一般與大型建物：民宅、高樓、超高層、工廠、百貨、醫院火警。
  - 工廠類：倉庫、農地工廠、鐵皮屋、化工廠、傳統市場。
  - 機構類：養護機構、外籍宿舍。
  - 其他：地下室濃煙、離火未熄、住警器響、電動車／儲能、冷氣室外機、太陽能板屋頂、建物氣爆、煮食不慎、誤報謊報。
  - 室外場景：資源回收場、加油站、雜草火。
- **進入方式：** 首車到場回報後，案件詳情出現「⚔ 進入戰術指揮」；或在地圖現場模式雙擊案件。
- **戰略／戰術分層：**
  - 進入後由你指揮現場各小組。
  - 指揮中心的受理、派遣、請求回覆改由戰略 AI 代理。
  - 按「返回指揮中心」或 Esc 離開後，現場改由 AI 指揮官依同一套模型處置。

### 時間尺度

場內動作以約 **1:10** 模擬，也就是畫面上的 1 秒相當於現實 10 秒：

- 走過一個房間約 18 秒。
- 爬一層樓約 22 秒。
- 一支氣瓶可在室內作業約 18 分鐘。

戰術畫面開著時，全局時間會放慢；戰略層的其他案件與派遣共用同一條時間軸，一起變慢。上方「時間 1:」可切換畫面時間與現實時間的比例：

| 比例 | 一支氣瓶（畫面時間） | 民宅火警全程（畫面時間） | 適合 |
|---|---|---|---|
| 1:2 | 約 9 分鐘 | 17～30 分鐘 | 練習、細部操作 |
| **1:3（預設）** | 約 6 分鐘 | 11～20 分鐘 | 兼顧 OODA 與節奏 |
| 1:5 | 約 3.5 分鐘 | 7～12 分鐘 | 熟練後、節奏較快 |
| 1:10 | 約 2 分鐘 | 3～6 分鐘 | 快轉（例如殘火處理） |

**為什麼預設 1:3：**

- 閃燃前兆、低壓警報、結構警告等事件，大約有 30～60 秒可以觀察、判斷、下令（完整走完一次 OODA），多組同時有狀況也來得及。
- 一件民宅火警約 15 分鐘，不會拖得太長。
- 1:2 的反應時間更寬裕，但一場要將近半小時；1:5 在多組同時告警時容易來不及。

上方「現場」計時顯示進入戰術指揮後經過的現實時間（換算）。

**戰略層的時限暫停：** 戰術畫面開著時，指揮中心其他案件的剩餘時間、公務時限與外縣市支援請求的回覆時限都會暫停，進線列表以「⏸」標示；回到戰略層後才繼續倒數。車輛移動與作業照常進行（跟著放慢）。開啟「事件暫停」後，MAYDAY、閃燃、爆燃、結構警告、坍塌、延燒鄰棟等重大事件會自動暫停，按空白鍵繼續。

### 畫面

- **樓層平面（俯視）：**
  - 外牆、門（含開門弧線）、窗、家具、地板材質。
  - 火、煙、溫度與搜索狀態。
  - 滑鼠停在空間上可看溫度、能見度、燃燒面積、含氧量。
- **樓層概況（左側）：**
  - 每層的起火、溫度、煙、受困、未搜索房間數與 MAYDAY。
  - 點選、滾輪或 `[` `]` 切換樓層；選取小組時自動跳到該組所在樓層。
- **四面周邊：**
  - 依大地圖判定各側是哪一級道路、鄰棟、農田、魚塭或水域。
  - 有路的一側才有出入口、才能停車。
  - 消防栓與送水口依實際方向落在某一側。
- **側欄：** 最上方固定顯示概況列（起火、火勢、受困、救出、未搜、RIT、MAYDAY），下方分四個分頁：

  | 分頁 | 內容 | 分頁上的數字 |
  |---|---|---|
  | 概況 | 幕僚建議、化災或風向、結構與設施、氣體偵測、跨縣市支援、請求增援、現場民眾 | 幕僚建議數 |
  | 水線 | 水源、供水與用水、水箱、送水口、每條水線的來源、入口與水壓 | 出水線數／可用線數 |
  | ICS | 傷患集結與後送、ICS 架構圖 | 已開設站點數、幕僚 |
  | 無線電 | 周邊與最近 30 則通聯 | — |

  現場民眾可詢問是否有人受困、起火位置、是否有瓦斯桶、門鎖狀況、樓梯位置。
- **管制牌看板（底部）：**
  - 小組依狀態分欄：入室作業、屋外勤務、RIT、換瓶・休息、待命、站點・後勤。
  - 牌面寫任務、位置、入室時間、氣量與疲勞；車停在畫面外時寫「已抵達（畫面外）」。

### 車輛停放

到場車輛依真實車長停在建物各側的道路上（停放在模擬端以公尺計算，畫面依此繪製）：

- **車長：** 幫浦車約 8.5 公尺、雲梯車約 11 公尺、救護車約 6 公尺，車與車間隔 2 公尺。
- **可停長度：** 每側為建物面寬加兩側各 8 公尺（鄰棟門前）。
- **車道數：** 一般道路可停兩排（路邊與外側車道），窄路只停一排。
- **停放順序：** 依優先度從建物正面中央往兩側排：雲梯車 → 幫浦車 → 救助、化災 → 排煙 → 水庫車 → 指揮車 → 救護車。
- **優先車種後到時：** 雲梯車等功能車晚到，會自動換到前面，其他車往外移。
- **停不下的車：** 列為「已抵達（畫面外）」，道路末端標示畫面外車數。
- **停車與步行時間：**
  - 每輛車到場後要停車整裝約 3 秒（現實約 30 秒）才能出發。可以先下令，整裝完成才會動身。
  - 畫面外的車依停放距離另加步行時間：每 12 公尺 1 秒，約現實 10 秒。
  - 畫面外的幫浦車拉的水線，每 20 公尺多接一條水帶，水壓跟著變低。
- **作業中的雲梯車：** 停在目標窗戶（或屋頂）正對的位置。

### 人員動作

- 小組在房間、走廊、樓梯間之間移動時，緩起緩停，不會瞬移換位。
- 朝向依實際行進方向轉動。
- 行進時排成縱隊，腳步交替；靜止時散開成小圈。
- 屋外待命的小組站在自己的車旁（建物與道路間的人行通道上）。

### 建物與格局

- **格局隨機產生：**
  - 民宅（透天）：樓梯間在側邊，前廳臨街，後側是臥室、廚房、浴室。
  - 高樓、醫院：主走廊兩側房間，有端部梯廳、中央梯廳、單邊外廊三種型態。
  - 工廠、賣場、倉庫：開放空間或走道型。
  - 所有格局都會隨機鏡射。
- **分戶住宅：** 公寓房間依戶分組，只有客廳的戶門通往走廊；戶門上鎖時整戶要破壞進入。
- **各樓層用途：**
  - 地下室是停車場與機房。
  - 三層以上公寓的 1F 是店面（臨街鐵捲門）；超高層 1F 是大廳。
  - 透天頂樓是神明廳；醫院 1F 是門診。
- **第二座安全梯：** 五層以上的走廊式建物與醫院、養護機構有兩座樓梯，分為「攻擊梯」與「避難梯」。
- **防火門：** 樓梯間的防火門有常閉、常開、被雜物卡住、被拆除四種狀態，小組到達前不知道。
  - 開著或拆除時，濃煙會灌進樓梯往上竄。
  - 老舊公寓與外籍宿舍常被卡住或拆走。
- **依報案內容產生現場：** 報案內容會反映在建物上，例如「從 B2 跑上來」就有兩層地下室、起火在 B2。
- **自動撒水設備：** 超高層、百貨、養護機構設有撒水設備。
  - 動作時把火壓在約三成並阻止延燒，但不會撲滅，仍需小組入室。
  - 約 20% 未動作，火會沿外牆逐層往上燒。
- **養護機構：** 值班護理人員會把濃煙中的臥床住民水平推到同層安全的房間。

### 特殊案類

- **離火未熄：** 戶門上鎖、廚房悶燒缺氧，破門開門有爆燃風險。
- **住警器響：** 可能只是油煙誤報，也可能是悶燒小火，或獨居長者倒地。
- **電動車／儲能：** 鋰電池熱失控，撲滅後復燃機率高，要持續冷卻。
- **冷氣室外機：** 火在外牆上，會燒破窗戶進入室內並沿外牆往上延燒。
- **太陽能板屋頂：** 斷電前板子帶電，雲梯只能水霧遠距射水。
- **建物氣爆：** 1F 炸成瓦礫，受困者埋在瓦礫中；瓦斯持續供氣，關閥前起火點撲不熄。
- **煮食不慎：** 公寓廚房起火，濃煙重。
- **誤報謊報：** 要逐戶查證後才會結案。
- **工廠類與機構類：**
  - 倉庫可燃物最多；鐵皮隔間延燒快一倍多；化工廠、市場常有瓦斯桶或化學品。
  - 養護機構與醫院有臥床者需要搬運；外籍宿舍受困人數多。
- **百貨挑空：** 濃煙與熱氣經挑空直接往上層竄。

### 小組與任務

到場的幫浦、雲梯、救助、排煙車與消防機器人各編成一組。

- **空氣瓶：** 入室小組有空氣瓶與體力；氣量不足以撤到屋外時，會自動撤出換瓶，換完回原任務。
- **倒地：** 高溫、閃燃或空氣耗盡會倒地發出 MAYDAY，需由 RIT 救援，否則殉職。

### 水線與排煙

- **佈線：** 每條攻擊線從幫浦車沿道路繞到入口，再經樓梯、走廊拉到射水組，最多 16 條水帶（約 320 公尺）。
- **水壓：** 水帶越長、樓層越高，水壓越低。線的顏色依水壓為藍、橘、紅；沒水或燒破時線會扁掉。
- **水源：**
  - 每輛幫浦車最多 2 線。
  - 消防栓那側沒人佔水時，只能用車上水箱。
  - 高樓應做送水口加壓，各樓層可直接接線。
- **排煙：** 選擇在哪個入口送風、開哪扇窗，決定煙往哪裡走。開口能降低煙層，但沒有同步射水時會讓火勢更旺。
- **鄰棟延燒：** 貼著鄰棟的房間燒得越旺，鄰棟受熱越高，滿了就延燒過去（評鑑 -6）。

### ICS 編組

側欄的「ICS 編組」是現場的指揮架構圖，每個方塊點一下就開設／撤除（站點）或指派／解除（職務）：

```
                 指揮站（現場指揮官）
          安全官 ─────┼───── 聯訪處
      ┌───────────────┼───────────────┐
    作業組          後勤組          救護組
   水源組長        待命集結區       救護組長
   搜救組長        氣瓶充填區       檢傷站
   前進指揮所      後勤照護區       醫療站
   除污站（化災）
```

- **站點**由對應的車輛擔任，開設後該車人員不能做其他事；帳篷搭在建物四角的路口，不佔車位。
- **職務**由幕僚擔任：開設指揮站後，每輛在場指揮車提供 2 名幕僚。

| 方塊 | 需要 | 效果 |
|---|---|---|
| 指揮站 | 指揮車 | 作業效率 +15%；提供幕僚 |
| 安全官 | 幕僚 | 設置人員管制板（之後才看得到各組氣量）；自動編成 RIT、MAYDAY 時派員救援、閃燃前兆時撤出小組 |
| 聯訪處 | 指揮站，且警方到場或另一輛指揮車 | 統一發布；沒有時，有受困者的案件每 90 秒扣 1 評鑑 |
| 水源組長 | 幕僚 | 自動佔水、送水口加壓、鄰棟周界防護 |
| 搜救組長 | 幕僚 | 自動派閒置的救助組搜索、雲梯救援窗口與屋頂受困者 |
| 前進指揮所 | 指揮站，五層以上建物 | 設在起火層下兩層，低壓的小組就近換瓶休息 |
| 除污站 | 化災車或化災應變隊 | 受化學污染的小組除污後才能再派 |
| 待命集結區 | 指揮車或一組幫浦組 | 新到小組在集結區整裝；沒有待命幫浦組時自動請求增援 |
| 氣瓶充填區 | 救助器材車（71） | 見下方說明 |
| 後勤照護區 | 救護車 | 隊員休息補水，疲勞恢復快 5 倍 |
| 救護組長 | 幕僚 | 自動請求救護車、開設檢傷站與醫療站 |
| 檢傷站 | 救護車 | 依傷勢優先後送，紅色傷患惡化減緩 |
| 醫療站 | 有 EMT-P 的救護車 | 等待後送的傷患惡化減為三成 |

**氣瓶充填區**

- 任一輛救助器材車（71）到場，司機就會自動開設灌充機，不佔用救助組的人力。
- 開設後換瓶 3 秒、不限數量。
- 開設前，每組只有車上 2 支備用瓶（換瓶 7 秒），用完就**無法再換瓶**，只能等 71 到場。
- 可以手動撤除；撤除後不再自動開設，要重新點方塊開設。

### 救護、化災與氣體偵測

- **救護分流：**
  - 救出的受困者檢傷為紅、黃、綠，在傷患集結處等救護車後送。
  - 沒有救護車時，傷患在現場持續惡化，撐不住就死亡（評鑑 -3）。
  - 所有傷患後送完才會結案。
- **化學災害：** 化工廠、資源回收場常有化學品外洩，濃度向外擴散並劃出熱區與暖區。
  - **防護等級：**
    - 預設消防衣帽鞋，只能應付低濃度。
    - 化災車到場後可換穿 A 級（每車 1 套）或 B 級（每車 2 套）。
    - C 級每人都有，但不能進濃煙或高濃度區。
    - A、B、C 級都不耐火。
  - **處置流程：** 化物辨識（I）揭露化學品與需要的防護等級；止漏（Z）在洩漏源作業；進過危害區的小組要除污。
- **氣體偵測：** 悶燒缺氧的空間 LEL、CO 會升高（爆燃前兆）；合成材質多的空間 HCN 較高。LEL 超標時，幕僚會建議禁止破窗開門。

### 結構、增援與報停

- **結構穩定度：** 依建物類型有高、中、低穩定度。
  - 受損 50%、80% 時安全官警告；80% 起火層以上禁止入室。
  - 100% 時燒得最嚴重的樓層坍塌。
- **消防專用升降機：** 六層以上的走廊式建物可啟用，直達起火層下兩層。
- **請求增援：** 直接向戰略層調派最近的各類車種。
- **報停：** 受傷隊員送醫後，該車返隊即報停一段時間。

### AI 指揮官

AI 指揮官依同一套戰術模型處置：

- **安全優先：** 先指派安全官、設人員管制板，入室前先編成 RIT（2 進 2 出）。
- **救人優先：** 已知有受困者時立即入室救人；搜索以已發現受困者、民眾指稱處、瓦礫優先。
- **攻擊順序：** 優先壓制受困者所在與相鄰的火點。
- **樓梯分工：** 兩座樓梯時指定避難梯，並關上被卡住的防火門。
- **其他：** 屋頂光電板起火時通報台電斷電；A 級防護衣不足時請求化災車。

### 室外場景

- **資源回收場：** 塑膠、紙類、金屬、電子廢料、化學桶、鋼瓶各區。
  - 車道是防火帶。
  - 大火會順風飛火。
  - 塑膠、紙類撲滅後容易復燃。
- **加油站：** 依報案內容，可能是已緊急遮斷、加油島車輛起火（油料外洩中），或卸油時起火。
  - 外洩中的油料讓起火點撲不熄。
  - 射水只有三成效果，泡沫車（57）、特殊化學車（01）才有效。
  - 用「止漏」關閉遮斷閥。
- **雜草火：** 空地或河堤，燒得快、順風擴大、會飛火。
  - **撲打：** 以打火拍撲打低矮火線。
  - **防火線：** 開在火頭下風、隔一區的位置。

### 交給轄區分隊善後

主要目標達成後，上方會出現「交給轄區分隊善後」。條件是火已撲滅、受困者與現場傷患都已處置、沒有化學品洩漏，只剩殘火處理。

按下後：

1. 離現場最近的分隊留一輛幫浦車殘火處理，其餘車輛立即返隊。
2. 畫面回到指揮中心。
3. 結案報告與評鑑照常計算。

### 結案報告

玩家指揮過的案件結案後會跳出報告：

- **分數與等級：** 時效、救援、安全、財損四項分數，以及 S～D 等級。
- **數據：** 首次出水、火勢控制時間、救出、罹難、MAYDAY 等。
- **檢討與時間軸：** 檢討項目與完整事件時間軸。

評分重點：

- **時效：** 首次出水 30 秒內、火勢控制 3 分鐘內滿分（以模擬時間計）。
- **安全：** MAYDAY、殉職、未編 RIT 即入室、未設人員管制板即入室都會扣分。

### 部署（GitHub Pages）

`.github/workflows/pages.yml` 會在每次推送到 `main`（或在 Actions 頁手動執行）時，把 `index.html`、`css/`、`js/` 原樣上傳到 GitHub Pages，不需要建置。

- **一次性設定：** Settings → Pages → Build and deployment → Source 選「GitHub Actions」。
- **查看部署：** 每次部署的紀錄在 Actions 的「Deploy to GitHub Pages」。新的推送會取消還在排隊的舊部署。

### 回歸測試

需要可 `require('playwright')` 的環境（無頭 Chromium），直接開啟 `index.html`，不需要伺服器：

```bash
node tests/regress.js all
```

也可以只跑其中一項：`load`（載入）、`map`（分隊可達與立體交叉）、`normal`（一般玩法 600 秒）、`tac`（8 個案類由戰術 AI 指揮到結案）、`handoff`（交給轄區分隊善後）。有失敗時結束碼為 1。

### 慣例

- `scene-*.js` 的 `sc…()` 由 `sceneLayers()` 依序呼叫，呼叫順序就是圖層順序；`onMap` 參數為 true 時是畫在大地圖上。
- `panel-detail-parts.js` 的 `d…()` 由 `panel-detail.js` 依序呼叫，各自回傳一個區塊的 HTML。
- `sim.js` 的 `step()` 每幀依序處理車輛、公務勤務，再對每個案件呼叫 `stepIncident()`。
- `RD` 是道路的功能類別（尋路用），`RG` 是道路等級（繪製與命名用）。
- 分層交會格（`HWL`）的國道層只為分層格配置：路徑場節點 `N*N + HLI[k]` 是格 `k` 的國道層，`cellOf(n)` 把節點換回格索引。

# KCFDDispatchCenterTheGame
Claude powered web game

高雄市消防局勤務指揮中心模擬遊戲。

## 試玩

- 本機：下載後直接用瀏覽器開啟 `index.html`，不需要安裝或建置任何東西。

## 指揮中心畫面

- 選取案件後，現場 2D 畫面預設放大在中央，全市圖縮到右欄；地圖右上角 ⇄ 可切換回大地圖。右欄的全市圖可按 ▁ 收合成一行標題，把空間讓給下方的案件詳情與 ARR 派遣，按「展開」恢復。
- 進線列表按下滑鼠就會選取；滑鼠停在列表上時排序凍結，平常每 2 秒才依剩餘時間重排。↑／↓ 可在案件間切換。

## AI 通話（選用）

按右上角的「AI 通話」，選擇供應商（Anthropic Claude 或 Google Gemini）、輸入自己的 API 金鑰並啟用後，新進線的電話改由 AI 扮演報案人：
在案件的通聯紀錄下方打字詢問，報案人會依該案件的實際狀況回答。

- 原本的腳本對話保留為備援：沒有啟用、連不上、金鑰無效或模型拒答時自動接手。
- AI 模式下案件進線間隔拉長為 2.5 倍，讓受理員有時間問話。
- 金鑰只存在瀏覽器的 localStorage，只會送往所選供應商的 API 主機（`api.anthropic.com` 或 `generativelanguage.googleapis.com`）；每次問答依該供應商的帳號用量計費。
- Gemini 請先按「測試連線」：會列出金鑰實際可用的模型；填的代號不存在（API 回 404）時會自動改用清單裡最接近的模型。

## 戰術指揮（建物火災）

民宅、高樓、工廠、百貨、超高層、醫院火警，以及煮食不慎、誤報謊報，在首車到場回報後，案件詳情會出現「⚔ 進入戰術指揮」（或雙擊現場畫面）。

- **戰略／戰術分層**：進入戰術畫面後，由你親自指揮現場各小組；指揮中心的受理、派遣、請求回覆、轉報 110／台電、公務勤務改由戰略 AI 代理。按「返回指揮中心」或 Esc 離開後，現場改由 AI 指揮官依同一套戰術模型處置。
- **樓層平面（俯視）**：每棟建物的格局都隨機產生、寬窄不一。民宅（透天）是西側一小座樓梯間（樓梯核上下是門廳走廊），加上一條小走道串起前廳（臨街，有時隔出儲藏室）、後側臥室、廚房與浴室；高樓、超高層、醫院是西端一小座樓梯間接分段的主走廊（樓梯間上下是門廳走廊），有時多一條往北或往南的支走廊，兩側房間大小不一，夾雜浴室、儲藏室等小房間；工廠與百貨是寬窄不一、彼此相通的開放賣場或廠區，偶有隔出的辦公室與倉庫，百貨東西兩端各有一座樓梯間（樓梯間只佔一小塊，其餘是門廳走廊）。房間依用途畫出家具（床、沙發、廚具、衛浴、辦公桌、病床、貨架、機台、紙箱），用途也影響戰術：儲藏室與賣場可燃物多、搜索慢，浴室幾乎燒不起來、搜索很快，病房搜索較慢。房間貼著外牆的方向就有對外窗。醫院另有 2–4 名臥床病患需要搬運。火經門延燒較快、隔牆較慢，有窗的房間會經外牆往上層延燒；煙經門擴散、沿樓梯間上竄，高溫加濃煙會閃燃。
- **樓層概況**：左側每層一列，寫出起火與最高溫度、煙的濃淡、在場組數、受困、民眾指稱有人、未搜索房間數、餘燼與 MAYDAY；點選、滾輪或 `[` `]` 切換樓層，選取小組時自動跳到該組所在樓層。水線會從幫浦車經入口、樓梯間一路畫到射水組；雲梯車停在目標房間外側（街道或後巷）。
- **四面周邊（依大地圖）**：建物四周依現場地圖判定為主幹道、一般道路、巷弄（大型車禁入）、產業道路、鄰棟或水域。有路的一側才有出入口（北、南、西側進樓梯間，東側進走廊盡頭）、才能停車；雲梯車只能架在面向可停大型車道路的窗戶。消防栓依實際方向落在某一側，送水口（五層以上的連結送水管）在最寬道路那側。
- **煮食不慎、誤報謊報**：煮食不慎是公寓廚房起火（只從一間廚房燒起、濃煙重、偶有一名受困者）；誤報謊報沒有火，首車到場只回報「未見明顯火光，逐層查證中」，要把報案樓層各戶都初期搜索過才會結案，查證完才研判是善意誤報還是惡作劇謊報。
- **俯視呈現**：外牆加厚，地板依用途分木地板、磁磚、水泥，開著的門畫出門板與開門弧線。消防車一律消防紅（救護車、警車白色），依車種畫出車頂設備：雲梯車有梯架與轉台、幫浦車有水帶床、水庫車有水槽、救護車白車身紅十字、排煙車有送風機。作業中的雲梯車會停到目標窗戶（或屋頂）正對的道路上，雲梯只架向面對自己停放側的窗戶，可以雲梯救援、雲梯射水、破窗排煙、垂直排煙與屋頂排煙。
- **現場民眾**：剛到場約 4 分鐘內有避難出來的住戶或管理員可詢問（側欄「現場民眾」）：裡面還有人嗎（會在房間標出「民眾指稱有人」，約七成五準確、偶爾誤報）、從哪裡燒起來（標出起火點）、有沒有瓦斯桶（標出位置；火燒到會爆炸）、門有沒有鎖（未問之前入口與房門是否上鎖不會顯示，要到門口才知道；有時住戶有鑰匙或遙控器）、樓上幾戶與樓梯在哪。AI 指揮時會自動問一輪。
- **側欄**：最上方一行精簡概況（起火樓層、火勢、受困、救出、未搜、RIT），接著是現場民眾、水源與水線（水源與佔水狀態、供水對用水、車上水箱、送水口、每條水線的來源車、入口、水帶條數與水壓條，以及出水／扁帶／燒破狀態）、傷患、站點、職務、周邊與無線電。
- **管制牌看板**：底部的小組以管制牌呈現，依狀態分欄：入室作業（依樓層排序、MAYDAY 置頂）、屋外勤務、RIT、換瓶・休息、待命、站點・後勤。牌頭顏色代表小組類型，牌面寫任務、位置、入室時間與氣量（有管制板時）、疲勞。
- **指令列**：分成「需指定目標」（先選指令再點畫面）與「立即執行」兩排。
- **人員管制板**：開設指揮站並指派安全官後，安全官約 10 秒會在入口設好管制板（地圖上標示），之後才看得到各組的氣量；在那之前小組卡片與現場的氣量一律顯示「？」，只能靠隊員回報低壓警報。
- **地下室與屋頂層**：高樓、百貨、超高層、醫院、工廠有機會多一層 B1，約三分之一的機率從 B1 起火。地下室沒有對外窗、雲梯用不上，煙只能經樓梯往上竄（開頂樓屋頂排煙口可以拉出煙道）。五層以上建物的受困者有人會逃往屋頂：樓層列最上方的「屋頂」可切到屋頂俯視圖，點屋頂可派入室小組從頂樓樓梯上去帶人下樓，或派雲梯車（屋頂在可達高度內）直接救援；頂樓樓梯間的煙會讓屋頂上的人慢慢惡化。
- **救護分流**：救出的受困者依當時狀況檢傷為紅（危急）、黃（嚴重）、綠（輕傷），在入口旁的傷患集結處等待在場救護車裝載後送（紅色一車一名、其餘一車兩名）。沒有救護車時傷患在現場持續惡化（黃會轉紅），撐不住就死亡（評鑑 -3）。側欄可「請求救護車」；所有傷患都後送完才會結案，獎金依送醫人數計算。
- **現場站點**：站點帳篷搭在建物四角的路口（不佔車位）；每個站點都要由對應的單位擔任，開設後該單位就不能做其他事（例如擔任檢傷站的救護車不能後送）。
  | 站點 | 需要 | 效果 |
  |---|---|---|
  | 指揮站 | 指揮車 | 作業效率 +15%；每輛指揮車提供 2 名幕僚可指派職務 |
  | 待命集結區 | 指揮車或一組幫浦組 | 新到小組在集結區那側整裝；沒有待命幫浦組時自動請求增援 |
  | 氣瓶充填區 | 救助器材車（氣瓶灌充機） | 換瓶 3 秒、不限數量；未開設時每組只有 2 支備用瓶，用完換瓶要 25 秒 |
  | 後勤照護區 | 救護車 | 隊員休息、補水與生命徵象監測，疲勞恢復快 5 倍 |
  | 救護檢傷站 | 救護車 | 依傷勢優先後送、裝載較快、紅色惡化減緩 |
  | 救護醫療站 | 有 EMT-P 的救護車 | 等待後送的傷患惡化減為三成 |
  | 聯訪處 | 指揮站，且警方到場或另一輛指揮車 | 統一發布；沒有時有受困者的案件每 90 秒扣 1 評鑑（最多 4 次）；結案評鑑 +2 |
- **疲勞**：入室作業會累積疲勞，移動變慢、耗氣變快；疲勞滿了自動撤出休息，恢復後回原任務。
- **職務指派（玩家輔助）**：開設指揮站後，可在側欄指派幕僚擔任職務，由他們自動處理一部分工作；名額為在場指揮車數 × 2。
  - 安全官：在入口設置人員管制板（之後才看得到各組氣量）；自動編成 RIT、MAYDAY 時派員救援、閃燃前兆時撤出小組
  - 水源組長：自動佔水、送水口加壓、鄰棟周界防護
  - 搜救組長：自動派閒置的救助組初期搜索，人數對不上時次級搜索，並以雲梯救援窗口與屋頂受困者
  - 救護組長：自動請求救護車、開設檢傷站與醫療站
- **鄰棟受熱與延燒**：貼著鄰棟那面牆的房間燒得越旺（開窗更快），鄰棟受熱越高（4F 以下才算，鄰棟較矮）。受熱過半安全官會警告，滿了就延燒過去（評鑑 -6、案件獎金打折）。幫浦組可做鄰棟周界防護（H，再點鄰棟）：停在與鄰棟相鄰的道路側（不能是對面）向外牆射水降溫，受熱降下來後會自動收線；如果兩旁都沒有道路，只能靠室內滅火。
- **佈線與出水**：每條攻擊線從供水的幫浦車沿道路繞到入口，再經樓梯、走廊拉到射水組，最多 16 條水帶（約 320 m）；拉不到就不能下令攻擊。水帶越長、樓層越高，水壓越低（線的顏色：藍＞橘＞紅，卡片與側欄顯示百分比），射水效果跟著打折。正壓排煙只沿送風入口通往各排煙開口（破窗、屋頂）的路徑排煙，也會讓這條路徑上已開窗的火點更旺；選擇在哪個入口送風、開哪扇窗，決定煙往哪裡走。消防栓那側沒有幫浦車佔水時只能用車上水箱（最多一線、用完就斷水）；高樓應派一輛幫浦組做送水口加壓，之後各樓層出水口可直接接線、水壓穩定（同時最多 3 線）。水帶經過高溫空間可能燒破，出水中斷 8 秒。
- **小組**：到場的幫浦、雲梯、救助、排煙車與消防機器人各編成一組。入室小組有空氣瓶（剩餘氣量不足以撤到屋外時自動撤出換瓶，樓層越高越早撤，換完回原任務；扛受困者前也會先估算氣量）與體力；沒有水線掩護的小組所在空間過熱會自動撤退；高溫、閃燃或空氣耗盡會倒地發出 MAYDAY，需由 RIT 入室救援，否則殉職。
- **任務分派**：先點小組（或按 1–9、點車輛），再點房間、走廊、道路或鄰棟；右鍵＝依小組類型與該空間狀態的預設任務。指令列依類別分組，滑鼠移到按鈕上可看說明。

  | 類別 | 任務（快捷鍵） | 說明 |
  |---|---|---|
  | 水線 | 入室攻擊 A | 帶水線進入火點射水，撲滅後自動往同層最近的火點推進，最後原地守線 |
  | | 過渡射水 E | 幫浦組先站到 1F、2F 窗外射水壓制火勢（約 10 秒），再自動轉入室攻擊 |
  | | 周界防護 H | 守住一個空間（例如樓梯間、受困者所在房間），讓火延燒不進來；點鄰棟則為鄰棟周界防護 |
  | | 侷限火勢 F | 到火點旁關上通往火點與濃煙的門，大幅減緩延燒與煙擴散；之後有人經過那扇門就會打開 |
  | | 殘火處理 Q | 翻搜燒過房間的餘燼並澆熄；餘燼未處理時可能復燃（約 150 秒後自然熄滅），有餘燼不會結案 |
  | 進入 | 破壞進入 B | 約半數入口是上鎖的鐵捲門或鐵門、部分房門上鎖（紅叉）；點道路預先破開該側入口，點房間破開該室門鎖。沒有預先破壞時，小組走到上鎖處會就地破門（救助組 4 秒、其他 9 秒） |
  | | 門控進入 K | 守在入口（點道路）或門邊（點空間）控制門的開度。入口最近有人進出卻沒人門控時，會形成進氣路徑，助長地面附近的火勢；門邊門控則壓低相鄰火點的燃燒 |
  | 搜救 | 初期搜索 S | 快速掃過，煙越濃越容易漏人；房間標「初搜」 |
  | | 次級搜索 D | 徹底翻找（較慢），找出初搜遺漏的受困者；房間標「次搜✓」。受困者要全部找到才會結案 |
  | | 屋頂救援 U | 從頂樓樓梯上屋頂帶民眾下樓（雲梯組則由雲梯直接救援） |
  | 排煙 | 破窗排煙 V | 打破窗戶建立排煙開口；缺氧悶燒的火場突然開口會爆燃（Backdraft） |
  | | 水霧排煙 W | 幫浦組開窗後以水霧把煙帶出窗外，本室與相通空間的煙快速下降 |
  | | 正壓排煙 P | 排煙組在入口架送風機，沿送風路徑把煙推向開口；沒有開口無效，也會讓路徑上已開窗的火點更旺 |
  | | 負壓排煙 N | 排煙組在窗口架排風機把煙抽出；不會把空氣灌進火場 |
  | | 垂直排煙 J | 在頂樓房間正上方屋頂開孔（由頂樓樓梯上屋頂，或雲梯），大量排出熱煙，該室不會閃燃 |
  | | 屋頂排煙 O | 開啟頂樓樓梯間的排煙口，拉出樓梯間的煙道 |

  | | 雲梯射水 M | 由雲梯從窗外射水；同層有入室小組時會把熱煙壓回室內 |
  | 調度 | 移動 G | 移到指定位置待命（例如先在起火層下一層集結） |
  | | RIT R | 於入口待命，MAYDAY 時入室救援 |
  | | 撤出 X、全員撤出 | 撤出建物 |
  | | 移車 T | 再點道路，把車移到另一側 |
  | | 送水口加壓 C | 幫浦組接連結送水管送水口，各樓層出水口可直接接線 |

  點道路也可直接下令：幫浦或雲梯車移車、排煙組在該側入口正壓排煙、室內小組撤出。空白鍵暫停。
- **水線呈現**：執行用水任務的小組，水線會從自己的消防車先拉到牆外通道、沿通道（轉角處轉彎）拉到入口門口，同一入口的多條水線並排收束後進入建物，再沿入室路線一路拉到人員身上，看得出這組是從哪個入口、走哪條路進去的。充水時線條飽滿鮮明（越粗水壓越高，顏色藍＞橘＞紅），沒水、燒破或還沒分到水時就扁掉變淡。
- **指定空間與預計路線**：下令後，目標空間外框會閃動，小組往目標的預計路線以虛點線標出；選取中的小組最明顯。
- **空間參數**：滑鼠停在任何空間上會顯示溫度（°C）、能見度（m）、燃燒面積／空間面積（㎡）、含氧量（%），以及搜索狀態、餘燼、缺氧悶燒（開口可能爆燃）、閃燃前兆等警示。溫度約在 600 °C 以上會閃燃；含氧量低於約 14% 時火勢燒不旺但煙濃，低於 13% 時突然開口會爆燃；能見度隨煙濃度降到 1 m 以下。
- **水線**：每輛幫浦車最多 2 線，受消防栓或水庫車流量限制；入室攻擊、過渡射水、防護射水、水霧排煙、雲梯射水都要占用一條水線，沒有分到水線的小組到位後無法出水。
- **戰術取捨**：入口沒人門控會變成進氣路徑；缺氧火場先射水降溫再開口；排煙開口能降低煙層、保護受困者，但沒有同步射水時會讓火勢更旺；正壓排煙要有開口才有效；雲梯射水會把熱煙壓回同層的入室小組；初期搜索快但會漏人，次級搜索可靠但花時間；水線不夠時先火勢侷限、把水線留給最關鍵的火點。
- **時間與事件暫停**：戰術畫面開啟時全局時間放慢（預設 ×0.5，可切換 ×0.25／×0.5／×1），戰略層的其他案件與派遣共用同一條時間軸，只是一起變慢。開啟「事件暫停」後，MAYDAY、閃燃、爆燃、結構警告、坍塌、延燒鄰棟等重大事件會自動暫停並以橫幅提示，空白鍵繼續。
- **幕僚建議**：開設指揮站後，右側會依現況列出最多 5 條建議（缺氧悶燒勿破窗、尚未設人員管制板、高樓改用送水口、結構受損應撤出、受困者位置等）。
- **結構穩定度**：依建物類型有高／中／低穩定度，火勢負載會累積結構受損；50%、80% 時安全官警告（80% 起火層以上禁止入室，AI 會撤出所有入室小組），100% 時燒得最嚴重的樓層樓板坍塌，該層人員重傷、受困者罹難。
- **前進指揮所與消防專用升降機**：地上 6 層以上的走廊式建物設有升降機，啟用後可讓小組直接到起火層下兩層以下的樓層；井道進煙時停用。起火層在 3F 以上時可在起火層下方開設前進指揮所，入室小組在該層整補氣瓶、縮短往返。
- **請求增援與報停**：右側「請求增援」可直接向戰略層調派最近的幫浦、雲梯、救助、救護、指揮、水庫等車種。現場隊員受傷送醫後，該車返隊即報停，戰略層不能再派（受傷 3 分鐘、殉職 15 分鐘）。
- **選取操作**：在平面圖拖曳可框選多組；Ctrl／Shift 點選可加選；管制牌卡片可點選、多選。觸控裝置會放大按鈕，點按空間可固定顯示參數。
- **結案報告**：玩家指揮過的案件結案後會跳出報告：時效、救援、安全、財損四項分數與 S～D 等級，首次出水、火勢控制時間、救出／送醫、罹難、燒毀、MAYDAY、殉職等數據，檢討項目，以及完整事件時間軸。
- **結果**：火勢全滅且受困者都已處置後殘火處理 8 秒即結案。受困者罹難、隊員殉職、建物燒毀過半都會扣評鑑。

| `js/main.js` | 面板更新、事件處理、主迴圈 |

各 JS 檔是一般 script（不是 ES module），共用同一個全域範圍：

- `index.html` 裡的載入順序不可更動（表格即為載入順序）。
- 新增的頂層名稱不能與其他檔案重複。
- `scene-*.js` 裡的 `sc…()` 函式由 `scene.js` 的 `drawScene()` 依序呼叫，繪製順序就是圖層順序。
- `panel-detail-parts.js` 裡的 `d…()` 函式由 `panel-detail.js` 依序呼叫，各自回傳一個區塊的 HTML。
- `sim.js` 的 `step()` 每幀依序處理車輛、公務勤務，再對每個案件呼叫 `sim-incident.js` 的 `stepIncident()`。
